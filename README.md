# Django Library Management System

A Django-based Library Management System with basic CRUD operations and database management.

## Overview
This project is developed using Python and Django to manage library records efficiently.  
It allows users to add, update, view, and delete book records through a simple web interface.

## Features
- Add new books
- View book details
- Update existing records
- Delete books
- Basic CRUD operations
- User-friendly interface
- Database integration

## Technologies Used
- Python
- Django
- SQLite / MySQL
- HTML
- CSS

## Project Structure
```text
Library/
│── manage.py
│── Library/
│── templates/
│── db.sqlite3
```

## Installation

1. Clone the repository
```bash
git clone <repository-url>
```

2. Navigate to the project folder
```bash
cd Django-Library-management-system
```

3. Install dependencies
```bash
pip install -r requirements.txt
```

4. Run migrations
```bash
python manage.py migrate
```

5. Start the development server
```bash
python manage.py runserver
```

6. Open in browser
```text
http://127.0.0.1:8000/
```

This project was created for learning Django framework concepts, database connectivity, and CRUD operations.
